# CrashCourse
XR Project

Learn music-making fundamentals and history behind music through teaching a curious, freshly-landed alien about what music is!
This concept expands on the idea that you learn efficiently by teaching the same principles you want to further understand. By beginning with the foundations and engaging directly, the player becomes part of the experience and learns more as they go. The basic tools help introduce music fundamentals and build foundations for how to make your own music.
